# 壘球落點紀錄表（慢壘）

在比賽現場用平板紀錄對手打者的擊球落點，累積資料後分析打者習慣、提供建議守備位置。

純靜態網站（HTML／CSS／JS），不需要網路、不需要伺服器。

## 檔案

- `index.html`：首頁
- `style.css`：版面樣式
- `app.js`：所有功能
- `images/`：圖示

## 使用步驟

1. **球隊／比賽**：新增對手球隊 → 新增球員（背號＋姓名）→ 新增比賽
2. **紀錄**：選打者 → 點球場落點 → 選擊球類型 → 選結果 → 儲存
3. **分析**：選球隊／打者／比賽，看散佈圖、熱區、建議守備與統計
4. **資料備份**：每場比賽後匯出 JSON 備份；CSV 可用 Excel 開啟

> 資料只存在使用中的瀏覽器裡，換裝置請用「匯出／匯入」搬移。
